**Part 6: Write A Homework Problem**  
**Problem:** An animal shelter is preparing to bring cats to an adoption event. The shelter has 59 cats, and each carrier can safely hold 3 cats. Write code that stores the total number of cats and the number of cats that fit in each carrier as variables. Your code should calculate and print:

1. The number of carriers that can be completely filled  
2. The number of cats left after filling those carriers  
3. The total number of carriers needed so that every cat can be transported to the event  
4. The shelter currently owns 15 carriers. Store this number as another variable and calculate how many additional carriers the shelter needs.  
5. Each new carrier costs \$20. Store the price as a variable and calculate the total cost of purchasing the additional carriers.  
6. A 5% sales tax is added to the purchase. Calculate and print the final cost of the additional carriers after tax. 

**What this question assesses:** This question is meant to assess the ability to use variables and operators in Python to solve a real-life problem. It requires the student to use modular arithmetic to determine how many carriers can be completely filled and how many cats are left over. It also assesses the ability to complete calculations involving subtraction and multiplication when determining the number and cost of additional carriers. I anticipate that the most challenging part of the problem will be determining the total number of carriers needed. The student has to recognize that if there are cats left over after filling the carriers, an additional carrier is still needed even though it will not be completely full. Another challenge might be determining which operators are needed for each part of the problem. Completing this problem will allow the student to gain a better understanding of how variables and modular arithmetic can be used together to solve an applied problem.

**Answer Key:** The code is provided in the file cat\_shelter.py

1. Number of carriers that can be completely filled: 19  
2. Cats remaining: 2  
3. Total carriers needed to transport all cats: 20  
4. Number of carriers that need to be purchased: 5  
5. Cost of buying the additional carriers: \$100  
6. Total cost of the additional carriers after tax: \$105
